# Security Policy

## Reporting a Security Bug

If you think you have discovered a security issue in any of the code, I'd love to hear from you. I take all security bugs seriously and, if confirmed upon investigation, I will patch them within a reasonable amount of time and release a public security bulletin discussing the impact and crediting the discoverer.

The best and easiest way to report a security bug is to email a description of the flaw and any related information (e.g., reproduction steps, version) to the author.
